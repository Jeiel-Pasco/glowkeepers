## World Layout (Unified RPG Hub & Stepped Valleys)

Replaced the split v1/v2 map (`BuildGreybox` 8-plot camp + `BuildZones` `r=1150` outer donut) with a single unified RPG world generated by `tools/BuildZones.luau` and defined in `src/shared/Zones.luau`:

```
r 0–80       WIZARD CAMP COURTYARD (safe hub at y=-1): campfire spawn, Scriptorium Desk, Grimoire
             Shelf, Bank, Wizard Gear Shop; 3 gates at r=82 (0°, 120°, 240°)
r 90–138     DUEL ARENA RING south of camp (centre z=114, r 24): flat dirt floor, no trees
r 82–270     LOWLAND WILD FOREST: random Neutral Forest Wisps & Runestone Brute, Raider Camps
             (60°/180°/300° wedges), roaming Raiders (Lv 15–22), Elder Orsi (r 104, 0°)
r 270–290    VALLEY THRESHOLD (~28 studs high) with trail ramps; Scout Captain & Knight Envoy at r 304
r 290–620    THREE LEVEL-TIERED AREAS (centre d 460, radius 160):
               - Area 1 (0°)   Whispering Woods  Lv 1–15   boss Runestone Brute (Lv 15)
               - Area 2 (120°) Raider Wilds      Lv 15–30  boss Elder Treant (Lv 30)
               - Area 3 (240°) Highland Ruins    Lv 30–50  boss Ancient Mineral Golem (Lv 50)
             Packs run front (d 345, ~entry level) to back (d 515, ~cap); boss at d 565
r 700        outer mountain rim + invisible wall (WORLD_R)
```

- **Shared Hub**: Crossing inside `r < 80` automatically banks carried loot. No 8 empty v1 plots.
- **Exploration**: Outside the hub gates, the glowing character tether beam is off. Neutral `forest_wisp` and `ashling` enemies re-roll a new random forest spot (`Zones.randomWildPos`) every time they respawn.
- **Navigation**: Players use the 3 elemental Gate Signs, NightGlow Lantern Trails, and real forest exploration.

## Combat & PvP

- **Rules live in `Shared.CombatRules`**, used by both server and client, so displayed cooldowns match enforced ones.
  - Hat and passive: +damage and cooldown cut (CDR capped at 40%).
  - Robe and Earth passive: less damage taken (capped at 50%).
  - Boots: shorter dash cooldown (never under 1.4 s). Leaf passive: faster regen.
- **M1 combo**: the 4th click within 1.2 s is a finisher (1.5× damage, bigger bolt) carrying the Grimoire's `m1Effect`: knockback, burn, slow, poison, chill, shock or pull.
- **Permafrost**: Frost hits from a wizard holding the Frost Grimoire add chill. 3 stacks Freeze (1.2 s root). Stacks melt after 4 s.
- **Who can fight whom**: never inside the camp courtyard (`r < 80`). Two players can fight when both stand in the Duel Arena Ring (`Zones.inArena`, centre `(0, 114)`, r 24) or both have War Mode on. War Mode is switched with `TogglePvp`, in camp only.
- **PvP damage** is ×0.5 with the PvP type curve. `combat.spec` checks there are no one-shots between even Lv 50 builds. An all-power build can still one-shot.
- **Deaths**: `PlayerDied(player, pos, killer?, duel)`.
  - Arena duels drop nothing.
  - A War Mode kill gives the killer +1 bounty and `20 + 30 × victim bounty` coins, into their backpack. The victim's bounty resets.
- **Studio testing**: set a local test player's (UserId < 0) `DebugGrimoire` attribute to a Grimoire type to give and equip that Grimoire with all four pages.

## Running the builder

Copy `tools/BuildZones.luau` to `src/server/_tmp/` (Rojo syncs it). Then in Studio **Edit**, run:
`task.spawn(loadstring(game.ServerScriptService.Server._tmp.BuildZones.Source))`
Watch workspace's `BuildProgress` attribute until `done`. Delete `_tmp` afterwards and save the place. Stop any playtest first.

Studio's Edit mode caches `require`. If `Shared.Zones` changed since an earlier build in the same session, the builder sees the old module (for example, `ARENA_R` is nil at line 225). Restart Studio, or clone `Zones` as `ZonesFresh` and point the builder's `require` at the clone for that run.
